Variables y tipos de datos

Aprende a guardar información, reconocer qué tipo de dato estás usando y recibir datos de una persona. Incluye ejemplos, cuestionario y un laboratorio interactivo.

⏱ 45–60 minutos📘 Clase 2 de 16🎯 Fundamentos
01

¿Qué es una variable?

Un nombre que usamos para referirnos a un valor.

Imagina una etiqueta pegada a una caja. La etiqueta dice nombre y dentro guardamos el texto "Sofía". En Python, una variable permite asociar un nombre con un valor para poder utilizarlo después.

nombre

Nombre de la variable

La etiqueta que escribimos en el código.

"Sofía"

Valor almacenado

El dato al que se refiere la variable.

Ejemplo
nombre = "Sofía"
print(nombre)
SALIDA
Sofía
Idea clave: cuando escribes print(nombre), no necesitas comillas alrededor de nombre. Python busca el valor asociado a esa variable.
02

Asignar y cambiar valores

El signo = asigna un valor a un nombre.

En Python, = no significa exactamente “es igual a” como en una ecuación matemática. En una asignación, indica que el nombre de la izquierda recibe el valor de la derecha.

Asignación paso a paso
edad = 20
edad = 21
print(edad)
SALIDA
21

La segunda asignación reemplaza el valor anterior asociado a edad. Por eso se imprime 21.

Reglas para nombrar variables

nombre

Válido: empieza con una letra.

edad_2

Válido: puede incluir números después del primer carácter y guion bajo.

2edad

No válido: un nombre no puede comenzar con un número.

Convención recomendada: usa nombres descriptivos y snake_case, como nombre_completo o precio_total. Python distingue mayúsculas de minúsculas: edad y Edad son nombres diferentes.
03

Los tipos de datos principales

El tipo indica qué clase de valor estamos manejando.

int

Números enteros

Sin parte decimal: 7, -3, 0.

float

Números decimales

Con punto decimal: 3.14, -0.5.

str

Cadenas de texto

Texto entre comillas: "Hola", 'Python'.

bool

Booleanos

Solo dos valores: True o False.

Un ejemplo de cada tipo
edad = 21                 # int
altura = 1.72             # float
nombre = "Sofía"          # str
es_estudiante = True      # bool

print(edad)
print(altura)
print(nombre)
print(es_estudiante)
SALIDA
21
1.72
Sofía
True
¿Por qué "21" no es lo mismo que 21?
21 sin comillas es un número entero. "21" entre comillas es texto. Aunque se vean parecidos, Python los trata de manera distinta: el número se puede usar directamente en operaciones matemáticas; el texto representa caracteres.
04

Descubrir tipos con type()

Pregúntale a Python qué tipo de dato está usando.

Inspeccionar datos
print(type(21))
print(type(3.14))
print(type("Hola"))
print(type(False))
SALIDA
<class 'int'>
<class 'float'>
<class 'str'>
<class 'bool'>

Convertir un tipo de dato

A veces recibimos un dato como texto y necesitamos convertirlo a número. Para ello existen funciones como int(), float() y str().

Conversión
edad_texto = "21"
edad_numero = int(edad_texto)
print(edad_numero + 1)
SALIDA
22
Atención: int("hola") produce un error, porque el texto no representa un número entero válido. Más adelante aprenderemos a manejar estos errores.
05

Recibir información con input()

Permite que el usuario escriba un dato.

La función input() muestra una pregunta y espera a que la persona escriba algo. Lo importante: el resultado de input() es texto (str), incluso si la persona escribe números.

Preguntar el nombre
nombre = input("¿Cómo te llamas? ")
print("Hola, " + nombre)
EJEMPLO DE EJECUCIÓN
¿Cómo te llamas? Ana
Hola, Ana

Para pedir una edad y usarla en cálculos, convertimos el texto a entero:

Leer un número
edad = int(input("¿Cuántos años tienes? "))
print("El próximo año tendrás:", edad + 1)
EJEMPLO
¿Cuántos años tienes? 21
El próximo año tendrás: 22

2. ¿Cuál de estos valores es de tipo str?

Resumen y progreso

Consolida estos conceptos antes de avanzar.

  • Una variable es un nombre asociado a un valor.
  • = se utiliza para asignar un valor.
  • int representa enteros; float, decimales; str, texto; bool, verdadero o falso.
  • type() permite consultar el tipo de un valor.
  • input() devuelve texto; convierte con int() o float() cuando corresponda.
  • Usa nombres descriptivos, como precio_total.
