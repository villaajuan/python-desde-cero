01

¿Qué es programar?

Dar instrucciones claras y ordenadas a una computadora.

Imagina que tienes un robot. Puede hacer muchas cosas, pero necesita que le digas qué hacer y en qué orden. Programar consiste en escribir instrucciones para que una computadora realice una tarea.

Algoritmo: una serie de pasos ordenados para resolver un problema.

Ejemplo: preparar una taza de café

①

Entrada

Conseguir los ingredientes y una taza.

⚙️

Proceso

Calentar agua y preparar el café.

☕

Salida

Una taza de café lista.

Muchos programas se pueden analizar con este modelo:

Entrada → Proceso → Salida
Recibimos datos, hacemos algo con ellos y producimos un resultado.
02

¿Qué es Python?

Un lenguaje para expresar instrucciones que la computadora puede ejecutar.

Python es un lenguaje de programación conocido por una sintaxis legible. Se usa para automatización, análisis de datos, inteligencia artificial, desarrollo web y muchas otras tareas.

📖

Legible

Su código suele parecerse a instrucciones sencillas.

🧰

Versátil

Sirve para proyectos pequeños y grandes.

🌱

Ideal para empezar

Permite aprender conceptos fundamentales sin demasiada sintaxis inicial.

En esta primera clase usaremos una instrucción muy común: print().

03

Tu primera instrucción: print()

Mostrar información en la pantalla.

Observa el código. La función print() muestra el contenido que colocamos dentro de sus paréntesis.

Tu primer programa
print("Hola, mundo")
SALIDA
Hola, mundo

Desarmemos la instrucción

print

Nombre de una función incorporada que muestra información.

( )

Los paréntesis contienen el dato que le pasamos a la función.

"Hola, mundo"

Un texto, también llamado cadena o string. Las comillas lo delimitan.

¿Por qué usamos comillas?
Las comillas le indican a Python que queremos representar texto literal. Por ejemplo, "2 + 3" es texto. En cambio, 2 + 3 es una expresión matemática que Python puede calcular.
¿Qué pasa si olvido cerrar las comillas?
Python mostrará un error de sintaxis porque no puede identificar dónde termina el texto. Los errores son parte normal del aprendizaje: léelos, busca la línea indicada y corrige el problema.
04

Experimenta: cambia el mensaje

Predice el resultado y luego compáralo.

Ejemplo con tres instrucciones
print("Estoy aprendiendo Python")
print("Mi primera clase")
print("¡Puedo programar!")
SALIDA
Estoy aprendiendo Python
Mi primera clase
¡Puedo programar!

Python ejecuta estas instrucciones de arriba hacia abajo. Cada llamada a print() crea una nueva línea de salida.

Prueba tú: cambia los mensajes por algo que te represente. Mantén las comillas y los paréntesis.
05

Laboratorio interactivo

Responde las tres preguntas y comprueba tu comprensión.

1. ¿Qué muestra este programa?

print("Hola")
La función muestra el contenido que está entre los paréntesis: Hola.

2. ¿Qué muestra este programa?

print("2 + 3")
Las comillas hacen que 2 + 3 sea texto literal, no una operación.

3. ¿Cuántas líneas imprime?

print("A")
print("B")
Hay dos llamadas a print(), por lo tanto se muestran dos líneas.
