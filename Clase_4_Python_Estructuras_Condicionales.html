Estructuras condicionales

1. ¿Qué es una condición?

Una condición es una pregunta que Python evalúa como verdadera (True) o falsa (False). Por ejemplo: “¿Está lloviendo?”

True · Sí

Llevar paraguas.

False · No

Salir sin paraguas.

2. La estructura if

if significa “si”. El bloque se ejecuta únicamente cuando la condición es verdadera.

edad = 20

if edad >= 18:
    print("Eres mayor de edad")

Resultado: Eres mayor de edad.

Importante: los dos puntos : abren el bloque. La indentación (normalmente cuatro espacios) indica qué instrucciones pertenecen al if.

3. if y else

else significa “si no”. Se ejecuta cuando la condición del if es falsa.

edad = 15

if edad >= 18:
    print("Puedes ingresar")
else:
    print("No puedes ingresar")

Como 15 no es mayor o igual a 18, Python muestra “No puedes ingresar”.

4. if, elif y else

elif significa “si no, si”. Permite evaluar varias condiciones en orden.

nota = 4.2

if nota >= 4.5:
    print("Excelente")
elif nota >= 3.0:
    print("Aprobaste")
else:
    print("Reprobaste")

Resultado: Aprobaste. Python revisa de arriba hacia abajo y ejecuta el primer bloque cuya condición sea verdadera.

El orden importa: si revisas primero nota >= 3.0, una nota de 4.8 también cumple esa condición y nunca llega a “Excelente”.

5. Combinar condiciones

and · Y

Ambas condiciones deben ser verdaderas.

or · O

Al menos una condición debe ser verdadera.

not · NO

Invierte el valor lógico.
edad = 20
tiene_entrada = True

if edad >= 18 and tiene_entrada:
    print("Puede entrar")
else:
    print("No puede entrar")

🧪 6. Prueba los condicionales

Cambia los valores para observar la decisión del programa.

7. Proyecto: sistema de calificaciones

En este ejemplo, 3.0 es la nota mínima para aprobar.

nota = float(input("Ingresa tu nota (0 a 5): "))

if nota < 0 or nota > 5:
    print("Nota fuera de rango")
elif nota >= 4.5:
    print("Excelente")
elif nota >= 3.0:
    print("Aprobaste")
else:
    print("Reprobaste")
  • float() convierte la entrada en número decimal.
  • or comprueba si la nota está fuera del rango.
  • elif evalúa las categorías restantes.

if

Si la condición es verdadera.

elif

Si la anterior fue falsa, prueba otra.

else

Si ninguna anterior se cumplió.
