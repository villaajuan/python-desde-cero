1. ¿Qué es una lista?

Una lista es una colección ordenada de elementos. Imagínala como una fila de casillas: cada casilla guarda un dato y tiene una posición.

frutas = ["manzana", "pera", "uva"] numeros = [10, 20, 30, 40] mezcla = ["Ana", 21, True]

Las listas se escriben entre corchetes [] y sus elementos se separan con comas. Pueden guardar textos, números, valores booleanos e incluso otros tipos de datos.

Índice 0

manzana

frutas = ["manzana", "pera", "uva"] print(frutas[0]) # manzana print(frutas[2]) # uva print(frutas[-1]) # uva: último elemento

Ojo: el índice empieza en 0, no en 1. Un índice que no existe produce un IndexError.

2. Consultar y medir

colores = ["azul", "rojo", "verde"] print(len(colores)) # 3 print("rojo" in colores) # True print(colores.index("verde")) # 2
Función / operador¿Qué hace?
len(lista)Devuelve cuántos elementos hay.
elemento in listaComprueba si un elemento está presente.
lista[indice]Obtiene el elemento de esa posición.
lista[indice] = valorReemplaza el elemento de esa posición.

3. Agregar, quitar y ordenar

tareas = ["estudiar", "practicar"] tareas.append("repasar") # agrega al final tareas.insert(1, "leer") # inserta en índice 1 tareas.remove("estudiar") # quita por valor ultimo = tareas.pop() # quita y devuelve el último tareas.sort() # ordena la lista

append(x)

Agrega x al final.

insert(i, x)

Inserta x en la posición i.

remove(x)

Elimina la primera coincidencia de x.

pop()

Elimina y devuelve el último elemento.

Consejo: sort() modifica la lista original. Para ordenar sin modificarla, puedes usar sorted(lista).

4. Recorrer una lista con for

nombres = ["Lina", "Mateo", "Sara"] for nombre in nombres: print("Hola", nombre)

El bucle toma un elemento a la vez. En cada vuelta, la variable nombre representa el elemento actual.

Lista + bucle = poder

precios = [2000, 3500, 1200] total = 0 for precio in precios: total = total + precio print("Total:", total) # 6700
