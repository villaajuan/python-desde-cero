Bucles while y for

1. ¿Qué es un bucle?

Un bucle repite instrucciones. En vez de escribir cinco veces lo mismo:

print("Hola")
print("Hola")
print("Hola")
print("Hola")
print("Hola")

Podemos escribir:

for i in range(5):
    print("Hola")

El resultado es el mismo, con menos código.

2. El bucle while

while significa “mientras”. Repite el bloque mientras la condición sea verdadera.

contador = 1

while contador <= 5:
    print(contador)
    contador = contador + 1

Salida: 1 2 3 4 5 (cada número en una línea).

  1. El contador comienza en 1.
  2. Python comprueba si contador <= 5.
  3. Imprime el valor y suma 1.
  4. Cuando el contador llega a 6, la condición es falsa y termina.
¡Cuidado con el bucle infinito! Si olvidas incrementar el contador, la condición puede seguir siendo verdadera para siempre.
# Incorrecto: puede no terminar
contador = 1
while contador <= 5:
    print(contador)
    # Falta contador = contador + 1

3. El bucle for

for recorre los elementos de una secuencia, como una lista o un rango.

for numero in range(1, 6):
    print(numero)

Imprime del 1 al 5. El límite final de range() no se incluye.

frutas = ["manzana", "pera", "uva"]

for fruta in frutas:
    print(fruta)

En cada vuelta, la variable fruta toma el siguiente elemento.

4. Entender range()

range(5)

Genera 0, 1, 2, 3, 4.

range(1, 6)

Genera 1, 2, 3, 4, 5.

range(2, 11, 2)

Genera 2, 4, 6, 8, 10.

La forma general es range(inicio, fin, paso). El inicio se incluye, el fin se excluye y el paso indica cuánto avanza cada vuelta.

5. ¿Cuál bucle elegir?

Usa for

Cuando sabes qué secuencia recorrer o cuántas repeticiones necesitas.

for i in range(3):
    print("Hola")

Usa while

Cuando quieres repetir mientras una condición siga siendo verdadera.

respuesta = ""
while respuesta != "salir":
    respuesta = input("Escribe salir: ")

7. Proyecto: tabla de multiplicar

Este programa pregunta un número y muestra su tabla del 1 al 10.

numero = int(input("¿Qué tabla quieres ver? "))

for i in range(1, 11):
    resultado = numero * i
    print(numero, "x", i, "=", resultado)

Prueba con el número 7. Después modifica el rango para mostrar solo cinco resultados o llegar hasta el 12.

8. Controlar bucles: break y continue

break

Termina el bucle inmediatamente.

for n in range(1, 6):
    if n == 3:
        break
    print(n)

Imprime 1 y 2.

continue

Salta a la siguiente vuelta.

for n in range(1, 6):
    if n == 3:
        continue
    print(n)

Imprime 1, 2, 4 y 5.

10. Misiones prácticas

🧠 Resumen

while

Repite mientras una condición sea verdadera.

for

Recorre elementos o rangos.

break / continue

Termina el bucle / salta una vuelta.

Idea clave: los bucles automatizan la repetición. Asegúrate de que los bucles while puedan terminar.
