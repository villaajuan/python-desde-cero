1. Operadores aritméticos

Un operador es un símbolo que indica qué operación debe realizar Python.

+
Suma

10 + 5 → 15

-
Resta

10 - 5 → 5

*
Multiplicación

10 * 5 → 50

/
División

10 / 5 → 2.0

//
División entera

10 // 3 → 3

%
Módulo o residuo

10 % 3 → 1

**
Potencia

2 ** 3 → 8

¿Para qué sirve %? Si repartes 10 monedas entre 3 personas, cada una recibe 3 y sobra 1. Por eso 10 % 3 devuelve 1. También permite saber si un número es par: numero % 2 == 0.
numero = 8
print(numero % 2)  # Resultado: 0 (es par)

3. Operadores de comparación

Las comparaciones producen un valor booleano: True (verdadero) o False (falso).

OperadorSignificadoEjemploResultado
==Igual a5 == 5True
!=Diferente de5 != 3True
>Mayor que8 > 4True
<Menor que2 < 7True
>=Mayor o igual5 >= 5True
<=Menor o igual3 <= 5True
edad = 21
print(edad >= 18)  # True
print(edad == 21)  # True
print(edad < 18)   # False
No confundas: = asigna un valor; == compara dos valores.

4. Operadores lógicos

and
Y

Ambas condiciones deben ser verdaderas.

True and False → False
or
O

Al menos una condición debe ser verdadera.

True or False → True
not
NO

Invierte el valor lógico.

not True → False
edad = 21
tiene_clave = True

puede_entrar = edad >= 18 and tiene_clave
print(puede_entrar)  # True
  1. Python comprueba si la edad es al menos 18.
  2. Comprueba si la persona tiene la clave.
  3. Como ambas condiciones son verdaderas, el resultado es True.

5. Orden de las operaciones

resultado = 2 + 3 * 4
print(resultado)  # 14

resultado = (2 + 3) * 4
print(resultado)  # 20

Primero se resuelven los paréntesis, luego las potencias, después multiplicaciones/divisiones y finalmente sumas/restas. A igual prioridad, normalmente se evalúa de izquierda a derecha.

6. Proyecto: calculadora en Python

Copia el programa en un archivo llamado calculadora.py y ejecútalo con Python.

print("=== CALCULADORA PYTHON ===")

numero1 = float(input("Primer número: "))
numero2 = float(input("Segundo número: "))

print("1. Sumar")
print("2. Restar")
print("3. Multiplicar")
print("4. Dividir")
opcion = input("Elige una opción: ")

if opcion == "1":
    resultado = numero1 + numero2
elif opcion == "2":
    resultado = numero1 - numero2
elif opcion == "3":
    resultado = numero1 * numero2
elif opcion == "4":
    if numero2 != 0:
        resultado = numero1 / numero2
    else:
        resultado = None
        print("Error: no se puede dividir entre cero.")
else:
    resultado = None
    print("Opción no válida.")

if resultado is not None:
    print("Resultado:", resultado)

Conceptos usados

  • float(): convierte la entrada en un número decimal.
  • input(): recibe información del usuario.
  • if / elif / else: permiten elegir qué instrucciones ejecutar.
  • == y !=: comparan valores.
  • None: representa la ausencia de un resultado.
